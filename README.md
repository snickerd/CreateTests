# Лабораторная работа №4
## Написание Unit-тестов

### Описание проекта

Проект предназначен для демонстрации модульного тестирования
на языке Python с использованием библиотеки unittest.

### Функциональность

- Вычисление площади прямоугольника.
- Вычисление периметра прямоугольника.
- Проверка корректности входных данных.

### Структура проекта

- rectangle.py — исходный код программы.
- test_rectangle.py — Unit-тесты.
- test_plan.md — план тестирования.

### Запуск тестов

Выполнить команду:

```bash
python3 -m unittest -v
```

### Результат

Всего разработано 10 Unit-тестов.
Все тесты должны завершиться успешно.
