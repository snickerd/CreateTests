# План тестирования
## Лабораторная работа №4
### Написание Unit-тестов

### 1. Цели и задачи тестирования

Цель тестирования — проверить правильность работы функций вычисления площади и периметра прямоугольника.

Основные задачи:
- Проверить правильность вычисления площади.
- Проверить правильность вычисления периметра.
- Проверить обработку нулевых значений.
- Проверить обработку дробных чисел.
- Проверить обработку отрицательных значений.
- Убедиться в отсутствии ошибок при корректных входных данных.

### 2. Описание тестируемого продукта

Тестируемый продукт — программа на языке Python,
предназначенная для вычисления площади и периметра прямоугольника.

Программа содержит две функции:
- area(a, b) — вычисляет площадь прямоугольника.
- perimeter(a, b) — вычисляет периметр прямоугольника.

Входные данные — длины двух сторон прямоугольника.
Выходные данные — числовое значение площади или периметра.

### 3. Область тестирования

Тестированию подлежат:
- функция area();
- функция perimeter();
- обработка нулевых значений;
- обработка дробных значений;
- обработка отрицательных значений.

### 4. Стратегия тестирования

Для тестирования используется модуль unittest,
входящий в стандартную библиотеку Python.

Применяется метод модульного (Unit) тестирования.

Проверяются следующие сценарии:
- обычные положительные значения;
- одинаковые стороны прямоугольника;
- нулевое значение одной из сторон;
- дробные значения;
- отрицательные значения.

Для проверки результатов используются методы:
- assertEqual();
- assertAlmostEqual();
- assertRaises().

### 5. Критерии приемки

Программа считается успешно протестированной, если:
- все 10 тестов выполняются успешно;
- результаты вычислений соответствуют ожидаемым;
- отрицательные значения вызывают исключение ValueError;
- ошибки при выполнении тестов отсутствуют.

### 6. Ожидаемые результаты

В результате тестирования ожидается:
- успешное прохождение всех 10 Unit-тестов;
- подтверждение корректной работы функций area() и perimeter();
- выявление возможных ошибок вычислений;
- получение отчёта unittest о результатах тестирования.

Ожидаемый результат запуска: Ran 10 tests — OK.
